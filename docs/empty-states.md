# Empty-state audit

Empty states describe the current condition, suggest one relevant next step, and use an action only when that action is wired to an existing feature. A filtered result is described differently from an empty vault. Guidance remains short so it does not crowd the workspace.

| Surface | Empty condition and action |
| --- | --- |
| Notes | The empty vault offers Create your first note. A search or tag with no matches offers Clear search and filters. |
| Links | Backlinks explain that linking from another note will populate the list; outgoing links explain wiki and Markdown links. |
| Tasks | A vault without tasks points to notes and Markdown checkboxes. An empty task view offers Show all tasks. |
| Calendar | An empty calendar explains dated content; filtered empty results can clear filters. The agenda suggests New event or another date. |
| Graph | An empty vault points to notes. Empty local and filtered global graphs offer Global graph or Reset graph filters. |
| Bases | No Base points to the name field. An empty result opens the Base query editor. |
| Canvas | No Canvas points to its name field. The board toolbar remains available when a Canvas has no cards. |
| Plugins | No installations directs users to the existing local bundle picker and permission review. |
| Comments | No threads invite a new comment for permitted roles. Resolved-only discussions explain the Show resolved control. |
| Sync | A signed-out configured account has a sign-in action. An unconfigured deployment explains that cloud sync needs Supabase configuration. |
| Bookmarks and quick switcher | Empty bookmark groups point to the add form; no switcher match suggests another spelling or shorter name. |
| Dashboards and study | Empty widgets describe the source content needed; the study library points to its import and create tabs. |
| Trash, recovery, activity, AI, study | Existing empty guidance remains; these screens are not changed by this pass. |

This pass changes presentation and navigation only. It does not create data or enable cloud features implicitly. Keyboard and screen-reader behavior still need browser review across all screen sizes.
