# Noor Canvas

Noor Canvas is the local visual workspace for a vault. Open it from the activity bar, primary navigation, mobile navigation, or **Show Canvas** in the command palette. A Canvas is a versioned document stored in IndexedDB. Cards referencing notes and attachments retain their stable vault IDs; the note Markdown and attachment bytes remain in their existing stores.

Create a Canvas from the Canvas sidebar. Add Markdown text, a vault note, an existing image, PDF, audio, video, or other attachment, a website, group, or frame from the toolbar. Select a card to edit its text, label, color, size, or position in the inspector. A note card opens its source note; selecting it also loads the full Markdown preview in the inspector, where links can be followed. Attachment media load lazily through local Blob URLs.

Drag to move a card. Shift-click selects several cards; drag an empty area to lasso. Use the **Pan** tool, Space-drag, a middle mouse drag, the minimap, or a touch drag in Pan mode to move the viewport. Ctrl/Cmd plus wheel, zoom buttons, and **Fit Canvas** control scale. Grid visibility and snapping are separate toggles. The toolbar aligns cards, applies horizontal, vertical, tree, mind-map, or flowchart layout, groups selected cards, creates a frame around them, and connects exactly two selected cards. The connector inspector changes labels, sides, and arrow endpoints. Canvas shortcuts include Delete/Backspace, Ctrl/Cmd+A/C/V/Z, Ctrl/Cmd+Shift+Z, and Ctrl/Cmd+Y while the board has focus. Undo history holds the last 50 document changes for the active Canvas in the current session.

Frames appear in creation order during presentation. **Present** shows one frame at a time; use the Previous and Next controls or left/right arrow keys, and Escape to close.

**Export** downloads a `.canvas` JSON file. File references use paths relative to the exported Canvas path. Standard JSON Canvas text, file, link, group, and edge fields are used where possible. Noor-specific card kinds, stable vault references, group membership, grid, viewport, and frame order live in a `noor-note` field. Import accepts a user-selected `.canvas` or JSON file up to 5 MB. Note and attachment references resolve against the current vault by ID or path; missing files remain visible as unresolved attachment cards. Full-vault ZIP exports include Canvas documents and remap note and attachment IDs on import. Folder ZIPs omit Canvases because they may reference files outside the folder.

Current limitations: the board renders every card and connector, so large documents may slow the UI. Layouts run on the main thread. Tree and flowchart currently use the same layered arrangement. Clipboard paste works for selections copied inside the same Canvas session; system clipboard text is written for portability, but external clipboard import is not implemented. Undo history and deleted Canvas recovery are local; deleted Canvases can be restored from the Canvas sidebar. Canvas documents do not yet have revision checkpoints or real-time collaboration. No PDF annotation or media editing is provided by Canvas cards.
