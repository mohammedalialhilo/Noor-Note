# PDF reader and annotations

PDF attachments open in Noor Note's local reader from the file explorer or a PDF link in Reading Mode. The reader uses PDF.js in a browser worker to render one page at a time. It provides page navigation, zoom, fit width, fit page, lazy thumbnails, and page-level text search. Text layers allow selection; a selection can become a highlight, a comment annotation, a copied quote, or a new Markdown quote note.

Annotations are `pdfAnnotation` sidecar objects in the vault's IndexedDB object table. Each has a stable UUID, a stable attachment UUID, a one-based page number, selected quote, optional comment, color, and normalized page rectangles. Rendering scales rectangles with the page. The PDF attachment Blob is never rewritten when annotating. Trash and restore keep its annotations; permanent PDF deletion and Empty Trash remove them. Full-vault and relevant folder ZIP exports include sidecars and remap IDs on import. A plain `.pdf` file remains readable in other applications, but its Noor annotations require the Noor Note ZIP manifest.

Copy page link and Copy annotation link produce ordinary Markdown PDF links. A link can include `#page=7&noor-pdf=ATTACHMENT_UUID&annotation=ANNOTATION_UUID`. The relative or vault-root path is usable as Markdown outside Noor Note when it matches the file location; the IDs let Noor Note find the PDF after a rename and locate the exact annotation. A rename may leave the readable path stale until it is updated in the note. A note created from a selection uses a relative path. Reading Mode resolves the link into the local reader. The annotation panel scans current note bodies on demand for backlinks and shows source note, line preview, and a jump to that note.

Current limits: native PDF text search reports matching pages and excerpts but does not paint search matches on the page. Image-only PDFs can be scanned page by page with the separate OCR workflow; corrected OCR text then appears in global search, not the PDF reader's native text search. PDF-native annotations, form filling, embedded files, PDF byte export with annotations, and a bulk annotation manager are not implemented. Backlink detection covers ordinary inline Markdown links and may miss unusual link syntax or fenced examples. The reader uses browser memory and PDF.js cache for the opened file, so very large PDFs need further performance testing. Its dialog is keyboard accessible, but a full WCAG 2.2 AA review remains pending.
